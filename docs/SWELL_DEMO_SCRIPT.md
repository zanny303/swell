# SWELL 3-minute demonstration script

**Important:** Use a real site only after the live-data checklist in `LIVE_TESTING_AND_API_SETUP.md` is complete. Otherwise explicitly introduce the walkthrough as a synthetic software demonstration.

## 0:00–0:25 — The problem
Show Earth Decision Studio. Say: "Environmental decisions are made across disconnected maps, satellite products, forecasts and stakeholder documents. SWELL connects the evidence to a place and to decisions, while keeping observations separate from modelled futures."

## 0:25–0:55 — Observe
Select the study site. Open source layers and show acquisition time, source, maturity, resolution, quality and provenance. Explicitly identify any unavailable or non-co-temporal sources.

## 0:55–1:25 — Understand
Select a cell or asset. Open evidence and Copilot. Ask what is observed, what is derived, what is inferred and what is still unknown. Show citations/evidence IDs and uncertainty limitations.

## 1:25–2:00 — Manipulate
Create an intervention on the map or adjust a supported parameter. Save it as a separate scenario. Explain that observed data and the baseline are immutable. Run the supported model and show the mass/numerical diagnostics.

## 2:00–2:35 — Compare futures
Compare baseline and alternatives using the same forcing/model configuration. Show spatial impact, time series, trade-offs and uncertainty status. Do not display uncalibrated probabilities.

## 2:35–3:00 — Decide and verify
Open the stakeholder decision record. Show evidence, assumptions, owner, action, human sign-off and the measurement needed to verify the outcome. Close with the loop: observe → understand → intervene → forecast → decide → verify.
