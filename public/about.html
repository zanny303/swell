SWELL: public read-only copy

This page set is a copy of the SWELL Decision Studio with the twin built from NASA NISAR data for Dallas-Fort Worth, USA (9 passes, built 2026-11-16). It needs no account.

Open the Decision Studio · Worlds · Code and instructions · Evidence files

Connecting data sources, rebuilding the twin from NASA's archive, saving decisions and the 3D city need the local app. In the repository: python run_swell.py, then open http://127.0.0.1:8000/.

Scenario numbers are model output under the inputs you choose. They are not observations, engineering designs or safety certifications.
