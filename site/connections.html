2Find the real radar passes over your place

Takes about a minute and downloads nothing large. It lists the actual NISAR passes and fetches rain, clay and paving for the box.
Public metadata discovery; downloading HDF5 still requires Earthdata login.

3Build the twin from that data

Reads only your site's window from each radar file online, then fits and tests the model. The twin is usually ready in several minutes and the Decision Studio link appears. It then adds five more satellites as evidence (GPM rain, SMAP soil moisture, Sentinel-1 motion, Landsat vegetation, open water), which can take 20 minutes more; each one is optional and reports if it could not run.
